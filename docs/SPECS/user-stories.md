# User Stories

## World Builder (via Web UI)

1. As a world builder, I can create a new world so I have a space for my characters and lore.
2. As a world builder, I can create characters with rich descriptions so the AI has material to work with.
3. As a world builder, I can create locations to anchor my world geographically.
4. As a world builder, I can edit characters and locations as my vision of the world evolves.
5. As a world builder, I can browse my stories and re-read favorites.
6. As a world builder, I can review lore artifacts after a story and decide what becomes canon.
7. As a world builder, I can browse all lore in my world and change my mind about kept/discarded artifacts.
8. As a world builder, I can delete a world when I want to start fresh.
9. As a world builder, I can see which stories feature a specific character or location.
10. As a world builder, I understand how to generate stories even though the button isn't in the UI.
11. As a world builder, I can delete a story I don't like (understanding its lore artifacts go with it).
12. As a world builder, I can see MCP setup instructions so I can connect my AI advisor for the first time.

## AI Advisor (via MCP)

13. As the AI advisor, I can read the full world context — characters, locations, kept lore, recent stories — so I generate consistent stories.
14. As the AI advisor, I can create characters and locations on behalf of the user during a world-building conversation.
15. As the AI advisor, I can save a generated story with links to the characters and locations it features.
16. As the AI advisor, I can save lore artifacts that emerged from a story for the user to review.
17. As the AI advisor, I can check a world for consistency issues and flag them to the user.
18. As the AI advisor, I can suggest connections between characters and locations the user might not have noticed.
19. As the AI advisor, I can collaborate with the user to design a new world from scratch — asking probing questions about tone, setting, and themes, then creating entities based on our conversation.
