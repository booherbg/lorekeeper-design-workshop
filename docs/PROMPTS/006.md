Good instinct — the Web Speech API (`speechSynthesis`) is built into every modern browser, zero dependencies. The voice "type" idea is interesting but has a constraint: the available voices are OS/browser-dependent, so we can't guarantee a "spooky" voice exists. 

What we *can* control: **rate, pitch, and volume**. So instead of mapping to actual voice fonts, we'd define mood presets that tweak those parameters:

- **Spooky**: slower rate, lower pitch
- **Calm**: slow rate, medium pitch
- **Friendly**: slightly faster, higher pitch
- **Dramatic**: varied rate, lower pitch

A play/pause button on each story card, with a small dropdown for mood. Simple, no dependencies, works offline.

One trade-off: `speechSynthesis` quality varies wildly across platforms. macOS voices are decent; some Linux/Windows defaults sound pretty robotic. But for a local tool, it's fine — and it's the kind of thing that's fun to ship even if imperfect.

Want me to go ahead with that approach? I'm thinking:
1. A `<button>` on the story detail page (and maybe the list view)
2. A small mood selector (dropdown or pill buttons)
3. Pure client-side JS — no server changes needed
